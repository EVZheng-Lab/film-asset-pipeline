# 场景篇：定调性、切场景、去重、描述、参照物、变体

> 通用的描述规矩（300 字、不写下游的活、只写需求不写为什么）在 `SKILL.md`「核心」一节，这里不重复。
> 角色见 `how-to-write-character.md`，道具与特效见 `how-to-write-prop-vfx.md`。

## 一、先定调性：年代 / 阶层 / 风格 / 地理位置 / 人种

不先定这五件事，描述只能凭"世家""老宅"这类词的第一印象写，而直觉常常是错的。
典型错法：剧本里有"世家""老太君""上将军"，就把客厅写成"传统偏旧、木质家具"；
可同一个剧本里出现的是当代拍卖行、银行黑卡、跑车、智能手机 —— 物质生活是当下，
那家人住的该是当代都市小区里的公寓。定错一件，后面每份描述跟着错。

1. **年代** —— 找剧本里**真实世界的品牌、机构、科技**（车型、拍卖行、银行、通讯方式）当锚点，比架空称谓可靠。
   很多短剧是"现实物质生活 + 架空政治军事身份"两条线并存：官职、军职、国名是编的，不代表房子车子也是古代的。
   一个真实品牌都没有，就看科技细节（智能手机、网约车、外卖），只定"大概哪个年代"。
2. **阶层** —— 不被自称的身份词牵着走，抓**具体数字与比较**：总资产、跟其他角色的量级差、
   别人怎么评价这家人、家族内不同分支的贫富落差。结论放进**故事内部的坐标系**
   （"在剧里是没落但还撑着体面的一家"），不套外部社会标签。
3. **风格** —— 现代物质生活和架空军政身份是两条平行线索，同一个人在不同场次可能切换（西装 vs 戎装）。
   每场问一句：此刻他是以现代身份出现，还是以架空军政身份出现？
4. **地理位置** —— 找真实地名、机构、方言用词、货币单位。没有就按题材给默认（国产短剧默认中国大陆），
   不凭感觉换国家 —— 建筑、街景、招牌文字都跟着它走。
5. **人种** —— 由地理位置推出，写进 `meta.worldview` 当全片默认。剧本明写的个别例外（混血、外籍）
   只写进那个底档的 `note`，不把全局改成"多种族"。底档里"二十出头女性"那句要不要点出人种，由这一条决定。

`meta.worldview` 只写结论（五件都要有）；拿不准的依据写进相关资产的 `note`，引用剧本证据（台词、场次号），
不引用"上面那张截图"这类只有当次对话才懂的说法。这不是考据：只读剧本自己给的线索，几分钟定个大概。

## 二、切场景时剧本自己的标记常常不可信

按内容重判，并在 `note` 里如实登记原文和依据。不要私自"修正"剧本。常见几类：

- **场记头被粘进正文或台词**（`……快吃吧！2-3祠堂夜内`、`34-1接上`）：全文匹配 `\d+-\d+` 再逐条认，只扫行首会悄悄漏场，
  而场次总数看着很整齐。
- **场次编号重复**：消歧登记为 `102-1*`（星号表示号是我们补的），原文写的号留在 `note`。
  不消歧的话 `sceneCount`、覆盖数和 `arc[].scene` 都只认一次，后一场在表里没有位置。
- **内／外标记与内容矛盾**：标"内"而 Δ 动作行里有人打伞、从巷子尽头走来，实为露天。
- **地名与内容不符**：标"海边"而台词说的是"你在河里溺水"；标"宫廷"而内容是"飞身上马、出宫"。

## 三、去重：靠内容，不靠地名

| 情况 | 例 | 做法 |
|---|---|---|
| 一个地名其实是几个地方 | "皇宫"6 场：太后处庭院 / 宫宴筹备处 / 密谈处，功能和人物完全不同 | 拆 |
| 几个地名其实是一个地方 | "寝殿"与"太后寝殿"，简称与全称 | 并 |
| 地名指错了地方 | 标"宫内"的几场，台词说"移驾内侍局" | 按台词证据改 |
| 一个院落里的几个空间 | 内侍局 = 洗作院 / 宿舍门口 / 前院 | 各建一份，共用 tag 前缀 |

**同一家族名下可能有多处地产**："某家院子"和"某人家客厅"名字相近，未必是一处。用两条证据交叉验证：
**在场人物**（族长在不在场，还是只有小辈的核心家庭）、**空间限定词**（带院子、别墅字样的多是祖宅，
从没提过院子大门的多是公寓）。

去重依据一定写进 `note`，这是使用者最要复核的一项。

## 四、场景 brief 与参照物

写四样（SKILL.md 第 3 步）：是什么地方 / 形制的通俗样子 / 一两处痕迹 / 参照物一件。

**档次判断照做，写出来要通俗。** 按身份判断这地方该有多讲究，但落笔不抄"庶民富户"这类结论，也不抄"乌头门""不用斗栱藻井"这类术语或否定式 —— 模型没见过、画不出"没有"。
写成看得见的对比：门面窄小 vs 大门气派森严，梁柱素净 vs 梁栿上施着彩绘。身份比尺寸更能说清一个地方。

> ✗ 只用一场夜戏。全片最讲究那处民宅的正堂：五间进深九架，勋戚人家该有的规格都在。
> ✓ 皇室远亲府第正厅之内，室内，夜里。厅堂开阔，梁栿粗壮、其上施着彩绘。板门闭合，只点厅内的烛。长案两端那对落地烛台是认得出的参照物。

### 参照物：三步推导，顺序不能反

参照物**不是这地方最好看的一件东西**，是给下游一套相对位置的说法（"跪在踏道之下""站在灯旁、面朝门"）。
所以它必须落在**演员真正表演的位置**上；不在戏发生的地方的锚点，物件和位置都对也没用。

```
第 1 步  这场戏在哪儿演？只看剧本的 Δ 动作行（位置证据在动作行，不在台词），读出表演焦点在哪一点
第 2 步  那一点上，这类空间本来有什么不可移动的东西？优先用已经写进 brief 的环境要素，不另外发明
第 3 步  过五条判据
```

| # | 判据 | 反例 |
|---|---|---|
| 1 | 不可移动 | 一盆花、一把椅子 —— 下一场就可能不在 |
| 2 | 唯一 | 两台一样的地秤是歧义；"两侧廊庑"到处都有 |
| 3 | 好认 | "甬道""石阶"是通用元素 |
| 4 | 画面里看得见 | "衣领内侧的布牌"任何角度都不入画 |
| 5 | 位置是这类东西本来就在的位置 | 见下 |

反过来做（先想一件好东西、再给它安位置）就必然编造。例：露天庭院写"廊柱下一对石雕瑞兽" ——
石狮长在大门两旁或栏杆柱头上，廊柱柱脚只有柱础；模型对石狮的先验太强，会把它画回大门口，
锚点每张图位置都不一样等于没有。而那句 brief 已经写了"石阶被踩得温润发亮"，剧本里接旨、被刺、倒地全发生在正厅前的踏道跟前 ——
**正确的锚点本来就在环境里**。第 5 条的判据不是"历史上有没有"，是"模型的先验会不会把它放在这儿"。

**能用痕迹就别用有规制的器物。** 使用痕迹和日常无规制的小物（踩白的路径、绳槽、旧水缸、老槐树、地秤）很稳；
有规制的器物（石狮、抱鼓石、扳指、翡翠镯）需要专门知识，没有来源约束就会变成编造。
同一位置两样都可选时选痕迹；器物的位置拿不准，就换一件痕迹类的，不去补考据。

依据写进 `note`（"接旨、倒地都在正厅前踏道跟前，故取踏道"），让人能复核。

## 五、场景变体

**判据：主场景那个空间，在这个变体里还在画面里吗？** 只有机位、氛围、状态三种；默认没有，剧本真的经历了这个变化才加：

| 轴 | 一句话 |
|---|---|
| 机位 | 切到自正堂台基上向南反打的视角 |
| 氛围·时间 | 改成夜里，院里点起灯笼 |
| 氛围·天气 | 改成雨天，地面积水 |
| 氛围·季节 | 改成秋天，满地枯叶，枝头只剩零星黄叶 |
| 状态 | 改成大火烧过之后，东半院覆一层灰烬 |

**换了空间就不是变体。** 例：露天庭院挂一个"改成夜里，视点移进正厅之内，庭院不入画"—— 镜头进了另一个房间，
原空间一个像素都不剩，该另建"正厅内"一份资产。同一空间里镜头往前挪了一点、主场景仍在画面里，写成「切到…的视角」。

**机位变体最容易滥加，也最容易漏加。** 过渡戏、全程一个机位在拍的（推门走过、环境交代）不加。
只有剧本的 Δ 动作行写出**不止一个观察点**才加，常见三种，别只认第一种：

1. 人物隔着门窗内外来回对话
2. 同一个房间两端各有一处调度焦点，人物在两端来回或分居两端对峙（甬道尽头与台基前、审判台与阶下）
3. 仪式性大场面（婚宴、寿宴、签约酒会、公堂、灵堂、法庭）—— 有"入口 ↔ 主位"轴线，几乎总有反打，默认去核实

一份场景覆盖几十场、服务不止一桩事件时（同一宴会厅先办寿宴再办签约宴），把这些场次的动作行都过一遍再下判断。
"这样分镜更好看"不是标准，剧本真的要拍两个方向才是。

**机位变体的 brief 只写切到哪个方向**，不写反打那边有什么 —— 交给模型的先验。唯一例外：反打方向上有一件必须露出的锚点或跨场景道具
（墙上挂着后面要参考生图的那幅画），点一句那件东西。

> ✗ 切到楼下街面向上仰视挑台的视角，3-1 某某下楼走到人群里时用
> ✓ 切到楼下街面向上仰视挑台的视角
