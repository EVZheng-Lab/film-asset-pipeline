# 角色篇：底档与服装

> 通用的描述规矩在 `SKILL.md`「核心」一节。这一份只管"这个人长什么样"；
> "这个人怎么演、说话什么声"在 `how-to-write-bio.md`，纪律不同，别混用。

## 一、三层压两层

| 层 | 落到哪 | 例 |
|---|---|---|
| 人（脸、年龄、身形、发质） | `characters[]` 底档，写一遍，不登记场次 | `@char_xiaoming` 小明 |
| 人 + 一套服装 | `outfits[]`，出图单元 | `@char_xiaoming_xuesheng` 小明 · 学生装 |
| 那套衣服坏了、脏了 | `outfits[].variants[]` 状态变体 | `@char_xiaoming_xuesheng_hurt` 受伤破损 |

光有一张脸出不了图，所以场次全部登记在服装上。脸只写一遍：每套服装各写一遍脸，几遍之间必然对不齐。
页面复制服装那一格时会自动拼上"底档 + 这套衣服"，所以服装格里不重复写脸。

出图时同一个人靠**脸图**保持（先出脸图，服装和状态变体都拿它当参考），规矩在 `h3-image-film-assets/references/film-assets.md`。
同一张脸、不是同一个人用 `sameFaceAs`，见 `SKILL.md` 第 5 步。

## 二、换整套衣服不是变体

判据：**这套衣服，在这个变体里还穿在身上吗？**

| 变化 | 判定 |
|---|---|
| 同一套撕破 / 湿透 / 蒙尘 / 染血 / 施法时身上泛光（出现在两场以上） | 状态变体 |
| 换一整套衣服 | 另建一份服装资产，`char` 指同一个底档 |

换装藏进变体，编辑出图除了脸没有共同像素，必然失败；盘点上还漏了一套真实要拍的服装。
build 拦"另一套 / 另一身 / 换一套 / 换一身 / 整套换 / 换成另 / 改成另一"，词表抓不全，每写完一个问一句。
换装与状态可以叠：学生装和西服两套、学生装带一个受伤版 = 两份资产，其中一份带一个变体。

## 三、收录门槛

跨不止一桩剧情事件，或剧本给了名字，才建档。短剧常一集一场、一场戏被切成三五个场次号，
只在一桩事件里露面的配角（店员、路人）单看场次号像"跨四场"，其实出完这一桩就不再出现，不建档。
按事件判，并在汇报里说明是按这条判的；一次性配角汇报里点一句"另有 N 个未建档"。

## 四、底档 brief：只写换了衣服也不变的

1. **年龄段与性别**（需要时点出人种，见 `how-to-write.md` 一）
2. **脸** —— 脸型、颧骨、下颌线。剧本写了独有辨识点（纹身、疤、痣、胎记）就写上；**剧本没写不编**（EV 2026-11-14 定）
3. **头发** —— 发质和大致长度。梳法、发饰跟着服装变，写在服装那一格
4. **身形** —— 结实、瘦削、肩宽、高矮

不写五官比例：模型对"二十七八岁男性方脸"先验极强，穷举反而压掉它。

## 五、服装 brief：从第一个字起就是衣服

1. **形制** —— 什么衣什么裤什么鞋，领子、扣子、层数；梳法和发饰也写在这里
2. **料子与做工，用通俗说法** —— 粗棉布、手编毛线、翻毛皮，针脚齐整还是歪扭。
   不写"襦裙""褙子"这类服制术语，翻成看得见的样子（"上身短衣、下身长裙，腰线提得很高"）
3. **一两处使用痕迹** —— 膝盖磨得起毛发白、裙摆一道水渍。旧 ≠ 没人管：
   有钱人的旧衣服洗得发白而没有破口，穷人的破了不补
4. **（推荐，不强制）参照物一件**：不摘的那件配饰（腰上的帆布工具带、左腕的方形钢壳表）。
   build 不要求服装写"参照物"三个字 —— 使用痕迹已经够跨镜头识别，强制会逼出复述痕迹的废句。
   想写就按场景那套三步推导（`how-to-write.md` 四），多一条陷阱：**会被姿态挡住** ——
   这套衣服的戏全是跪着，腰侧的东西被裙摆挡死，就换成跪姿里看得见的（袖口、领缘）。
   同样优先用痕迹，不用有规制的器物（扳指、翡翠镯、补子都容易出时代错）。

**颜色照写**：固有色是识别特征（"洗旧的蓝白校服"），抽掉了同一个人两次生成连衣服颜色都会不一样。配色方案不写。

## 六、不写表情、姿势、性格

| 不写 | 为什么 |
|---|---|
| 表情、情绪、眼神、神情 | 资产图是中性站姿的形象底板，不是一个镜头 |
| 姿势、动作、手势、站姿坐姿 | 同上，每个镜头各自的事 |
| 性格评语（温柔、高冷、精明、气质、看起来很…） | 渲不出来 |

要表达"这人不好惹"，写看得见的东西：下颌线硬、衣领扣到最上一颗、指节有旧伤。
build 用 `EMOTION` / `TRAIT` 两张词表扫底档、服装、服装变体的 brief 和变体名。
性格有正当去处（角色档案），但这里**不给豁免**：写服装手痒想写性格时，那句话该去 `bios[]`。
