# 角色档案篇（`bios[]`）

> 这一份跟场景、角色、道具那几份**不是同一种东西**。那几份是出图资产，每句话喂给图像模型，
> 所以有"不写性格""每格单独读懂""300 字是质量上限"这些规矩；角色档案**不出图、不进图像提示词**，
> 是表演与声音的底本，后面写视频提示词时每场改写了再用。纪律不通用，别串。

## 零、它在哪一层

规则依据是 Higgsfield 官方的 ACTING skill 与 Cinema Studio 项目书（下文"rule N""§N"指它的条目）。官方把角色拆成四种生命周期，我们补第五种：

| # | 是什么 | 生命周期 | 落在哪 |
|---|---|---|---|
| ① | 外观描述 | 写一次，逐字复制进每条提示词 | `characters[]` + `outfits[]` |
| ② | 声音（Voice prompt） | 写一次，原样贴进 audio 字段 | `bios[].voice` |
| ③ | 表演底本（acting master profile） | 写一次，每场改写、核不动 | `bios[]` 八块 |
| ④ | 每个镜头的表演 | 下游每镜现写 | 不是我们的活 |
| ⑤ | **阶段状态** | 剧本里发生了什么事 → 他因此成了什么样 | `bios[].arc[]` |

**为什么要有③**：没有它，下游每个镜头把"焦虑"各自翻成一串动作（这次看手表、下次搓裤缝），几次之间没有东西保证是同一个人的习惯 ——
那是角色漂移在行为层的翻版。

**为什么要补⑤**：官方假设一份档案全片有效（§8.2 `Never contradict the master`）。有弧光的角色（开篇开朗、后半段沉默）
只拿着"开朗"那张卡，下游会一路照开朗演到底。所以**八块写的是开场状态**（他第一次出场那会儿），后来变了什么写进 `arc[]`。
声音、习惯动作、步态都是"此刻心里什么状态"的外在表现，经历真把人压垮了都可能变，甚至长出新习惯；
真正永不变的只有身体事实（在底档）和他身上发生过的那件事（过去时，写在 `posture` 的来历里）。

**这一层只补到「事实」为止**：剧本里发生了什么、他因此成了什么样，谁查都是这个答案 —— 归我们；
**从第几场起让观众看见他变了**是节奏判断（同一件事可以让观众提前预感，也可以突然一记重锤）—— 归导演，我们不写。

没有弧光的角色（本人不变、处境在变；喜剧配角；只推剧情的）`arc` 整个留空，开场状态就是全片状态，合法不算漏项。别给每个角色都硬铺三段。

## 一、两道墙（两个方向都有闸门）

**第一道：哪一层写什么。**

| 方向 | 禁什么 | 为什么 |
|---|---|---|
| `bios[]` | 服装与相貌词：衣服、衣裳、外套、夹克、工装、制服、套装、裤子、裙子、鞋子、料子、布料、脸型、颧骨、鼻梁、发型、刘海、身高、体重 | rule 6 `No wardrobe. The profile must survive any costume change.`；相貌在底档里，重写一遍就是两个版本的脸 |
| `characters[]` / `outfits[]` | 表情、姿势、性格词（`EMOTION` / `TRAIT`，不给豁免） | 出图资产是中性形象底板 |

判据：**换了衣服，这份档案还成立吗？** "紧张时把领口扣到最上一颗"—— 他光膀子那场怎么办？改成"紧张时手会去够颈侧"。

**第二道：哪个时期写在哪儿。**

| 方向 | 禁什么 | 为什么 |
|---|---|---|
| 八块 | 跨时期词：后来、后期、渐渐、越来越、到了最后、最终、一路 | 两个时期挤在一格里，下游不知道现在该演哪个 |
| `arc[].after` / `state` | 场次分配：后半段、前半段、中段、片尾、结局时、之后每场、以后一直、起就一直、"第 N 场/集之后/起" | 替导演把节奏决定做了 |

判据：**这句话是剧本里发生过的事，还是我替导演决定的节奏？**
例外：`posture` 里的来历（"早年扛货落下的"）是前史、过去时，所以词表刻意不收"当年/早年/从前/落下的"。
那件事**发生**在哪一场是事实，写进 `arc[].scene` 字段，不写进散文。

## 二、八块（开场状态，块序固定，别重排）

所有字段（八块、`voice` 四项、`superObjective`、`arc` 的 `after`/`state`）共用：单格 ≤300 字、不留占位符、不写下游词（rule 7 `No camera, no color`）、
不写服装相貌词。档案**可以**谈全片（`superObjective` 本来就是全片级的），不受"跨行指代"那条约束。

| 块 | 写什么 | 硬要求 |
|---|---|---|
| `posture` | 体态 + 它的来历（rule 8 `Physique carries biography`）："两肩常年往前收着，站定时重心压在整只脚上 —— 库区扛货落下的" | 年龄体格在底档，不重写 |
| `engine` | 心理引擎一句，要能解释上一块那个体态怎么长出来的："他认定先扛住，人家才看得见你，从不先喊累" | 必填 |
| `vocalProfile` | 说话在**戏里**怎么变：速度往哪移、什么时候破音、越急越快还是越慢 | 必填；跟 `voice` 必须吻合（`voice.manner` 说越急越轻，这里就不能写急了会喊） |
| `tics` | 招牌小动作 / 压力下的小动作 / 掩饰行为 / 那张脸的面具 | 必填；**每一条带触发条件** |
| `gait` | 步态，拆重量、步幅、躯干手臂、头 | 必填；**必须取名**，引号包住 |
| `crack` | 面具塌掉的精确条件 | 必填；**要有条件** |
| `softeningTarget` | 唯一让他真正软下来的那个人或东西 | 唯一可省的一块；给就只给**一个**（rule 5 `One — not two.`） |
| `eyeLife` | 扫视与注视目标、眨眼频率与质量（紧张时成串快眨、控场时慢而有意）、眼里有光、**眼睛先于头到位** | 必填（§7 `mandatory in every profile`，死眼是 AI 表演头号破功点）。刻意的静止写成"眨眼少、慢、有意，目光仍缓慢有目的地移动"，不是冻住 |

⛔ 八块合计 **≤400 字**（`voice` / `superObjective` / `arc` 不计）。理由不是压先验（档案不喂图像模型），是可用性：写成千字小传，下游没人会通读一遍再写一个镜头。

**tics 带触发**（rule 2 `Tics without triggers are decoration; tics with triggers are dramaturgy`）：格式是「什么动作 + 什么时候/为什么」。
> ✗ 他会转手里的硬币 ✓ 掂量一件事的时候，那枚旧硬币在指节上来回走

build 只认得几个触发说法（的时候、时候、一旦、每逢、每当、遇到、碰上、只要、听到、提到、被人、当着、面前、一见、每次、要是），
没报错不等于每一条都带了，写完自己数一遍。

**gait 取名**（rule 3）：引号里一个自造名，把一串生物力学描述压成下游每场对齐用的把手。
> ✗ 走得慢，脚步沉 ✓ 一种「扛货的走法」：步子短，落脚先着外侧，肩膀不摆，走多远都这个速度

不会走路的角色做**转移适配**，不删：写"轮椅操控风格"，一样取名、一样带触发（"急起来推得又快又碎，撞门框也不减速"）。

**crack 要条件**（rule 4，至少一条 `However, when X — …`）：先有面具，再有让它塌掉的精确条件；build 用同一张触发词表查。
> ✗ 偶尔会露出真情绪 ✓ 有人提到他弟弟，那张平脸半秒就散了：喉结先动一下，眼睛往地上找 —— 随即察觉，把手插回口袋，重新抹平

## 三、`voice` 四要素

`register` 音区与音色 / `tempo` 速度与停顿 / `accent` 口音与出身 / `manner` 腔调及压力下怎么变。
⛔ 必须是对象、四项都不许空。拆成四个字段是为了让"四件齐"查得动，写成一句话缺一件也看不出来。

交付纪律：原样贴进 audio 字段、每次说话都贴、不按场次改（写进汇报，见 `SKILL.md` 第 9 步）。
"不按场次改"不等于永远不变：声音真的随弧光变了（开朗高频 → 沉默低频），在那个阶段的 `arc[].voice` 另给一整套四要素（⛔ 同样四项齐）；
贴哪一版由导演定。`accent` 原则上不变（口音是出身）。声音没变就不写，页面自动沿用开场那一版。

## 四、`superObjective`（必填）

贯穿全片想要什么，下游每场的目标都是它的一步。写成**朝着某个人的动词**，不写状态（状态演不出来）：
> ✗ 想被认可 ✓ 让厂里那些老师傅承认他不是只会出力的

它是推每场目标用的依据，不进那段表演底本。

## 五、`arc[]`：后来变了什么（可选）

按剧本时间从早到晚排，每段：

| 字段 | 必填 | 写什么 |
|---|---|---|
| `after` | ✓ | 触发这个阶段的那件事："儿子被带走那天之后" |
| `scene` | | 那件事发生在哪一场 —— ⛔ 要能在场景表（含变体）的 `scenes` 里查到 |
| `state` | ✓ | 只写这个阶段**变了的**那几样 |
| `voice` | | 声音真变了才给，四项齐 |

1. **锚事件，不锚场次。** "儿子被带走之后"剪辑怎么调序都成立，"第 47 场之后"一调序就失效。
2. **只写变了的**："肩背仍是含的，但下巴抬起来了；急了不再变快，改成一字一顿地慢。"页面按阶段复制时自动带上八块，重抄就是两个版本的身体。
3. ⛔ 单段 `state` **≤150 字**；⛔ 八块 + 所有 `state` 合计 **≤700 字**（页面给的成品是"八块 + 累积到该阶段的所有 state"，要一眼读完）。
4. ⛔ **最多 4 段。** 超过基本是在按场次切，不是按转折切；相邻两段是同一个转折的，并掉。
5. ⛔ 有 `scene` 的段要按剧本时间顺序排（页面顺序累积，排反了成品就拼反了）。

`crack` 与 `arc` 的区别：`crack` 是一瞬间塌掉又收回，收完还是那个人；`arc` 是一个时期换成另一个时期，不回弹。
常见组合：`crack` 的触发阈值在后面的阶段变松了 —— 写进那一段的 `state`。

## 六、块状存，不揉成散文

官方要求的"一段流畅散文"（`One flowing paragraph`）说的是每场改写之后进提示词的那段，不是存档形态。
块状存才能逐块上闸门，出了问题也知道是哪一块。揉成散文是下游的活。
