# 道具篇与特效篇

> 通用的描述规矩在 `SKILL.md`「核心」一节。收录门槛、状态变体、特效分界表的要点在 `SKILL.md` 第 6 步，这里写细节。

## 一、关键道具

### 收录：跨场景，按事件判

**下一次出现时，观众会不会认出它是同一件？** 会才收（定情信物、随身兵器、反复传递的钥匙）。
只有跨场景复用的东西才有漂移风险、才值得建一份资产锁；只出现一次的交给模型的先验，列出来反而压先验。
build 拒绝只覆盖 1 个场次的道具（主资产一场 + 变体一场也算）。
但短剧一场戏常切成几个场次号，只在一桩事件里出现完就不再出现的（被扫在地上的那盒手表、当场签完的合同）不建档；
跨了好几桩事件的（一对婚戒：取出、摘下、再摘下、互戴）才是要锁的。判掉的在汇报里点出来。

**与场景的分界是搬不搬得动**：地秤、落地烛台、石雕是场景的参照物，写在场景 brief 里；玉佩、钥匙、信、照片是道具。

### brief 写四样

1. **是什么东西** —— 一把老式黄铜挂锁钥匙、一张巴掌大的黑白合影
2. **料子与做工，通俗说法** —— 黄铜、相纸、素银、粗陶；镂空的菱形柄、边沿摸得圆润发亮
3. **一两处最好认的细节，这就是道具的参照物** —— 齿部三个深浅不同的豁口、正面一道斜向折痕。
   道具跟着人走、没有固定位置，所以**不走场景那套三步推导**，只问"这件东西身上哪一处最好认"；
   build 不要求道具写"参照物"三个字。那处细节要看得见，优先用痕迹损耗，别用有规制的纹样形制
4. **画面上有没有引用别的资产**（见下）

不写谁在用它、什么时候用、为什么重要。

### 状态变体：同一件东西变了，不是换成另一件

判据：**这件东西，在这个变体里还在画面里吗？**

| 变化 | 判定 |
|---|---|
| 同一枚玉佩碎裂 / 烧焦 / 褪色 / 沾血 | 状态变体 |
| 同一把剑被激活后发光、符咒亮起来（光贴在那件东西上） | 状态变体（`@prop_jian_on`），不进特效表 |
| 换成一枚仿制的、赝品、替代品 | 另一件东西，另建资产（`@prop_yupei_fake`） |

真假调换是常见桥段，混成一份等于盘点漏了一件道具，下游也画不出"看得出差别"。
build 在**变体** brief 里拦"另一件 / 另一枚 / 另一把 / 另一张 / 换一件 / 仿制 / 赝品 / 复制品 / 替代品"；主资产本身是赝品合法。

### `refs`：道具画面上画着别的资产

照片、合影、油画、肖像、绣像、通缉令（画着某个角色）；建筑画、舆图（画着某个场景）。
这类道具**不能用文生图** —— 凭文字再描述一遍那张脸，出来必然不是同一个人。登记 `refs`，必须走参考生图，被引用的图先出：

```json
"refs": ["@char_along_gongzhuang", "@loc_warehouse"]
```

- **指到服装级或场景级，不能指底档**：底档只有脸没有衣服，照片上这人穿哪套？build 拦，并把这个角色现有的服装 tag 列出来。
  引用场景同理，指到具体资产或**具体变体**（白天那版还是烧过之后那版）。
- **不能指另一件道具**：信装在匣子里是两份独立资产，不用 `refs`。道具出现在某个场景里是 `scenes` 的事，也不用 `refs`。
- 必须指向已存在的 tag。页面给有 `refs` 的道具打蓝框「⚑ 必须走参考生图」。汇报里写清出图顺序。

## 二、特效

### 收录：会重复出现、要保持一致，而且是独立释放出去的东西

**这个特效下一次出现时，观众会不会认出它是同一个？** build 拒绝只覆盖 1 个场次的特效；一次大招切成三个场次号，不等于重复出现。
归类分界表在 `SKILL.md` 第 6 步之二。道具发光 vs 道具放出来的东西：光贴在剑身上是道具变体；
剑挥出去、反复出现的一道剑气是特效，`from` 指回那把剑（激活态那个变体也行）。人也一样：
指尖那团持续的金光是服装状态变体，她推出去、在空中飞的一道冲击波是特效。

### 描述分两段：静态 `brief` 与动态 `motion`（EV 2026-11-13 定）

| 字段 | 给谁 | 写什么 |
|---|---|---|
| `brief` 静态 | 图片模型 | 特效**本体**长什么样。资产图是灰底上一个孤立的本体 |
| `motion` 动态（必填） | 视频模型 | 每次都一样的运动规律：从哪儿发出、怎么扩散或收拢、离身体越近越亮、所过之处带起什么 |

判据：**一张静态图画得出来吗？** 画得出来进 `brief`，画不出来进 `motion`。

静态 `brief` 写四样：**是什么**（一团光、一圈气浪、一道光门）/ **形态与颜色** / **一两处最好认的特征**（这就是它的参照物）/
**大概多大**（"一人多高""拳头大"，不写米数）。build 在 `brief`（含变体 brief）里拦：

- 发出部位、贴着谁：指尖、掌心、手掌、皮肤、身体、身上、全身、周身、手臂 —— 发出者登记在 `from`，跟身体的关系写进 `motion`
- 随时间或位置的变化：渐渐、逐渐、越来越、越靠近、越贴近、越远、慢慢、缓缓 —— 写进 `motion`
- 人物词：人物、角色、众人、一群人、两拨人、过肩（资产图不放人；"一人多高""站得下两个人"这类比大小的说法不拦）
- 节奏与时长：慢动作、慢镜头、升格、降格、几秒、秒钟、时长、持续时间、一闪而过 —— 每个镜头的剪辑决定，`motion` 里也不写
- 下游词照常拦；注意"光晕"是镜头光学词，特效自己的光写成"一圈发白的光""边缘泛着蓝光"

> ✓ 静态：一团柔和的金光，里面流动着细碎的金色光点，像被风吹起的金粉。外缘一圈飘散的细碎光尘最好认。
> ✓ 动态：从指尖或掌心透出，越贴近皮肤越亮，向外慢慢淡开；外缘的光尘不停向四周飘散。
> ✗ 静态：从掌心透出的金光，越贴近皮肤越亮 —— 发出部位和变化混进了给图片模型的那段

### `from`：谁发出的（可选）

```json
"from": ["@char_along"]
```

只许指已存在的**角色**（底档或服装）或**道具**（含状态变体）；指场景、指特效会被拒。
**可以指底档** —— 跟 `refs` 相反：`refs` 要拿成图当参考，必须指到穿哪套；`from` 只登记"这是谁的技能"，技能跟着人走。
没有发出者（传送门、空中的裂隙）就整个省掉。页面显示成"发出者"，不进复制文本。

### 阶段变体

同一个特效的不同阶段（蓄力 / 释放 / 消散，剧本真的分阶段出现过才建），或剧情里形态变了（黑化换色、升级变大），认得出的那一处还在。
另一招、另一种技能是另一份特效资产（build 在变体 brief 里拦"另一种 / 另一招 / 另一个技能 / 换一招 / 换成另 / 改成另一"）。
变体只写改了什么；变体的 `motion` 可选，这个阶段动起来跟主资产不一样才写。
