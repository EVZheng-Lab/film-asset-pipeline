# 资产图提示词：固定格式、参考图、尺寸

> 给 MiniMax H3-Image 写资产图提示词时读。提示词用中文写，引号里给的是可以直接用的句子。
> 资产图**不是一个镜头**，是下游反复拿来当参考的定稿（参考生图、编辑换机位、贴进视频提示词），所以格式固定：
> 画幅、版面、背景、光、有没有人，不按"这张图怎么好看"自己选。

## 每张都要有的

- **开头一句说这是什么图**（下面每类给了开头句），再布局，再细节。
- **质感**：结尾写"照片级写实，电影剧照质感。"（角色写"照片级写实的棚拍照片，电影剧照质感，皮肤自然。"）
  不写"游戏""渲染""概念设计""插画""设定图" —— 写了就出那种画风。
- **字**：结尾写"画面里没有任何文字、字母或数字。"剧本写明画面里必须有的字例外：用引号写出那几个字和位置，
  再写"除此之外画面里没有其他文字、字母或数字。"编辑图写"不添加任何文字。"
- **少堆质感形容词**：H3 会把"起球""毛孔"这类词放大成满身凸点、过锐的皮肤。
- 画幅和尺寸不写进提示词，写在出图单的 `size` 里。

## 四类资产的固定格式

### 1. 角色 —— 三视图

| 项 | 规定 |
|---|---|
| 画幅 | 16:9（16MP：5472x3072） |
| 开头 | "一张电影角色定妆照，由三张棚拍照片并排拼在一张 16:9 的画面上。" |
| 版面 | **左** 全身正面、从头到脚；**中** 全身背面、带头；**右** 3/4 侧面头肩特写，脸和肩转约 45 度，眼睛直视镜头 |
| 左格带头 | H3 做不到稳定去头（EV 2026-11-13 定：左格带头）。左格的脸小、细节易糊，以右格特写为准 |
| 背景 | 三格同一块纯色**中性中灰**棚拍背景 |
| 光 | "一盏柔和的定向棚拍光从左侧打来，阴影自然过渡"。整部戏的三视图都从左侧，文生图和编辑图一样 |
| 姿态 | 中性站姿，双臂自然垂在身侧。表情只在右格写一句中性的 |
| 背面 | 背面看不到的辨识点（小臂内侧的纹身、脸上的痣）写明"中格背面看不到它"，否则会画到背上或另一只手上。这是"不写否定句"的例外：说的是哪一格看不到，不是让模型画"没有"。手臂外侧这类背面也可能露出一点的，同样这么写 |
| 一致性 | 写明"三格是同一个真人，穿同一套衣服" |
| 用词 | 写"棚拍照片""定妆照"；**不写**"角色设定图""三视图设定""厚涂"（会滑向插画、概念设计） |

**辨识点插图**（EV 2026-11-13 定）：剧本给了辨识点（纹身、疤、胎记、痣）时，在整张图**左下角**加一张贴纸式小插图放这处特写，
带一圈细白边，叠在灰背景上，不挡左格的人。没有辨识点不加；这套衣服把辨识点盖住了（长袖遮住手臂纹身）也不加，
写一句"长袖盖住了纹身，左下角不放插图"（同上，是例外）。

长相（副导演的角色底档）和这套服装写进同一条提示词：先长相（年龄、脸型、眉眼、骨相、肤色、身形、发型），再从头到脚的衣服鞋饰。

### 2. 场景 —— 完整的全景、空场景

| 项 | 规定 |
|---|---|
| 画幅 | 21:9（16MP：6272x2688） |
| 开头 | "一张全景，一眼看全整个地方：<什么地方>。" 写成"3/4 斜角、相机略高"会被画成高处往下拍的一块局部 |
| 机位 | "相机在人站着的视线高度"，不俯拍。用简单的话，不写监控视角、鱼眼这类术语 |
| 室外 | **要有天空**；开阔的地方写明地平线在画面哪里（"地平线在画面上三分之一处"），被建筑围住的院子看得到一块天就行 |
| 室内 | 斜着看过房间，同时看到两面墙和地面，主要陈设都入画。车内、电梯这类小空间不适用，看全整个座舱即可 |
| 此刻状态 | 空场景也要看得出这场戏时的状态，靠东西写：灯开没开、床单铺没铺、器械摆没摆开、桌上的饭吃到哪 |
| 人 | **空场景**，只写"空无一人"。**不写**"空荡""光秃""什么都没有"（H3 会理解成没有东西，画出样板间） |
| 参照物 | 副导演给的那件"认得出的参照物"必须清楚地在画面里 |
| 氛围 | 一句氛围落成看得见的细节（雾在哪、光从哪来），**前景保持清晰** |
| 光 | 场景里真实存在的光源和方向（窗光、灯、天光），不写笼统的"电影感光" |

H3 场景的毛病和写法：

- 爱把同类东西排成阵列。**不逐件写数量和位置去纠正** —— 写得越细越多，模型越把它当主角去堆，数量也不守。
  只写"有长椅"，加一句布局原则（像真实公园那样随意散布）
- 大面积同一种铺地（卵石、碎石、一色的地砖）会画成一整片重复的纹理。大块地面写成分区（铺装、草地、树影交错），或者让它占得少
- 高度写数字或"齐腰高"它不听，用旁边的东西比："矮墙只到空调外机的一半高"
- 门外、窗外不写就是一片黑，写出外面是什么（灯亮着的走廊、院子里的路灯）
- 写进去的每一处缺陷都画得很显眼很刻意。缺陷写成整体程度（"用了几年，有正常使用的磨损"），点名的破损只留给剧情需要的
- 中式建筑光说名字结构会错（回廊画成两排柱子中间露天铺砖）。把结构写出来：一条带屋顶的廊，屋顶下是砖地，廊外一侧是水池
- 屏幕、仪表、标签：写"屏幕上是几条彩色波形，没有可读的字"，不然会编出乱码字

**不加全局调色**（褪色胶片、低对比、黑位提起、高光压暗、远景溶解、60/30/10 配色）：这些指令会让 H3 整张图发灰、过曝。

### 3. 道具 —— 产品照

| 项 | 规定 |
|---|---|
| 画幅 | 1:1（16MP：4096x4096）；细高的 3:4（3552x4736），扁长的 4:3（4736x3552） |
| 开头 | "一张 3/4 俯拍的产品照：一件<什么东西>，单独一件，完整入画，四周留白。" |
| 背景 | 中性灰色哑光台面，干净无杂物。放不上桌的大件（车的外观、轿子、棺材）改成灰色棚拍地面 |
| 光 | 柔和的定向光，带一点自然投影，看得清材质 |
| 文字与标志 | 表面没有字和标志就正面写出来："表面素净，没有任何字和标志"；再加无文字声明 |

一件道具的几种状态（完好 / 碎裂 / 激活发光）各出一张，不放在同一张图里。

### 4. 特效 —— 灰底上的孤立本体

特效指**独立的、能被释放出去的东西**（冲击波、传送门、地面光环、缠到别人身上的光索）。身上的光不是特效，画进角色图（分界见 ad-asset-bible）。
缠在人身上的特效（光索）也只画光本身的形态，不画人、不画人台 —— 视频模型会理解它缠在人身上。

| 项 | 规定 |
|---|---|
| 画幅 | 1:1（4096x4096）；竖着长的（光柱）3:4（3552x4736），只贴着地面铺开的（法阵）16:9（5472x3072）。**贴地的光环上面还竖起光幕、光柱的，按竖的 3:4** —— 实测（2026-11-17）同一个瞬移特效出 16:9，两个种子光幕都只剩一圈短短的毛边，3:4 才立得起来 |
| 开头 | "一张高成本奇幻电影里的视觉特效剧照：<什么特效>，拍得像真实空气里真实的光。" 不写"魔法特效"这类泛称 |
| 内容 | **只有特效本体**，居中、完整入画。"没有人、没有手、没有身体，也没有别的环境。" |
| 背景 | 纯色**中性中灰**，跟角色三视图同一种灰。贴地的特效可以保留一块同色地面当落点 |
| 瞬间 | "凝固的一个瞬间"，写它此刻的形态 |
| 机位 | 贴地的（光环、法阵）相机略高于地面斜着看，看得出是一个圆；立着的、飘在空中的平视 |
| 尺度 | 画面里没有人，尺度用文字跟人比："直径够两个成年人并肩站进去""比人高一截" |
| 用哪段 | 只写静态的样子；从哪发出、怎么动（副导演的 `motion`）是给视频模型的，不进图片提示词 |

**要华丽，像电影特效，不像游戏贴图**（只写"一圈金色光环，往上冒光尘"出来一圈细光加一把均匀粒子，太游戏）。写进三样：

1. **层次**：核心一道白热的细线，外面一圈更宽的光带，光带上有流动的纹路
2. **跟空气和地面交互**：光在地面打出一片暖光、照亮贴地薄雾；光柱里的空气有热扭曲
3. **形态和颜色有变化**：拉长的火星、螺旋光带、大小不一的光点，越靠近源头越密越亮；颜色从白热过渡到浓色再到边缘的深色，跟冷灰背景拉开对比

## 同一资产的多张图：用参考图，只编辑一次

同一个人的几套服装、一件资产的几种状态，各自从文字出图，模型没法知道是同一个（同一段长相描述、同一个种子，两张文生图的脸明显不是一个人）。
所以要拿**文生图出的原图**当参考出（编辑）。

**编辑提示词的写法**（一整段，按这个顺序）：

0. 版式：参考图的左下角插图不沿用（"左下角插图不用"），这套露得出辨识点就在目标图里把插图重新完整写一遍。
1. 先定义参考图里要用的东西："<Picture 1>三格里的年轻女人是<Subject 1>。"
2. 说清这张参考图提供什么、哪些不用："<Picture 1>只提供她的身份：脸、五官、发色、身材和辨识点；它的衣服、鞋、发型、配饰和左下角插图都不用。"
3. "目标图是……"，把这张图的版面完整写一遍（跟文生图一样的固定格式），再写每个 Subject 怎么保留：
   "<Subject 1>部分保留：脸、五官、发色和身材不变，衣服、发型和妆换掉。"
4. 写变了的东西最终的样子（"她穿着……"），不写"把……换成……"
5. 结尾写质感和"不添加任何文字。"

**角色：第一套服装的三视图就是身份图，其余服装和状态变体都拿它当参考。**（EV 2026-11-16 定）

- 不单独出脸图。每个角色排在第一的那套服装（盘点里这个角色的第一份服装资产）用**文生图**出三视图，16MP，
  长相和这套服装写进同一条提示词。它同时是这套服装的资产图和这个角色的身份参考。
- **第一套选能露出辨识点的那套**（短袖露出小臂纹身）：辨识点在全身照里看得出在哪个部位，左下角的贴纸插图负责放大细节。
  剧本里没有能露出来的衣服，就在提示词里把部位写清楚（"左小臂外侧正中，手肘和手腕之间"）
- 其余服装、所有状态变体：拿第一套的三视图当参考，**编辑一次**。按上面的写法，把三视图版面和这套服装 + 状态完整写一遍，
  状态写到全身每个看得见的部位（脸、头发、手、鞋、头饰、衣服），不能只写衣服。
  辨识点在这个状态下变不变（施法时纹身发不发光）按剧本，剧本没写就不变。光在手上时，手可以在身侧微微翻开、掌心朝外。
- 编辑出来的三视图照样遵守辨识点插图的规矩：这套衣服露得出辨识点就在左下角加插图，盖住了就不加。
- 第一套自己的状态变体（白裙 + 挽发），同样拿第一套的三视图编辑。
- 同一张脸的两个人（底档写了 `sameFaceAs`）：没有自己的身份图，服装都拿被借脸那个角色的第一套三视图当参考，
  `<Picture 1>`只提供脸型和五官，发型、妆、肤色状态、身材按这个人自己的设计写。

**场景：**

- **画面里有某人形象的场景**（遗照、雕像；副导演把形象登记在场景的变体上）：主资产是空着的底图，文生图
  （空相框、看不清脸的雕像）；带形象的变体拿底图 + 那个人的身份图（第一套服装三视图，`<Picture 2>`只提供右格特写里的脸）两张当参考，
  编辑一次放上去；反打等其他变体也从底图编辑，画面里看得到那个形象的同样带上身份图。不拿已经放好形象的那张图再编辑。
- **衍生场景**（填了 `basedOn` 的：在主区域全景里看得见的区域，比如开放式的餐厅、厨房）拿主区域的全景文生图当参考出；
  它自己的变体（夜景、反打）**也拿那张全景图**，不拿衍生区域编辑出来的图。
- 没有 `basedOn` 的场景（同一栋楼里看不见的其他房间）各自文生图，风格靠 `_design` 里的共用约定（每条提示词里写进用得上的那几句）。
- 场景变体拿主场景的文生图当参考。
- 场景 `refs` 指向的人：用他的身份图（第一套服装三视图）；他 `sameFaceAs` 了别人，就用那个别人的。

**道具**：状态变体拿主道具的文生图当参考；有 `refs` 的道具（照片、油画上画着某人某处）把被引用的那张图带上。

**只编辑一次。** 参考图必须是文生图出来的干净原图，不能拿编辑出来的图再去编辑；要改好几处就合成一条提示词一次改完。
每轮编辑都过一次 VAE 压缩和重画，上一轮的噪点被当成细节放大：实测同一张图连续编辑，第 2 次已经噪点大到不能用。
蒸馏版只能 6 步、CFG 1，没有参数能调。

**编辑时参考图缩到约 4MP，出图用约 9MP，不用 16MP。**
官方编辑工作流把参考图缩到约 4MP、出图尺寸跟着缩完的参考图走，所以默认是 4MP 出。
实测（2026-11-16，同一参考图、同一提示词）：4MP、6MP、9MP 出图都干净，9MP 的全身照五官明显比 4MP 清楚；16MP 坏掉 ——
背景斑驳、皮肤冒斑、衣服没换干净。参考图 16MP 时也一样坏。参考图缩到 4MP 由出图脚本自动做。

编辑出来的版面和细节偶尔跑偏（中格背面变正面、靴子款式变了），属于概率性的，换种子重出。

## 出图单的字段

- `size`：这一张实际出图的像素，宽x高。文生图按上面的 16MP；编辑用 9MP：
  16:9 4000x2240，3:4 2592x3456，4:3 3456x2592，1:1 3008x3008，21:9 4576x1952（都是 32 的倍数）。
- `refImage`：按 `<Picture 1>`、`<Picture 2>`… 的顺序写参考图的 tag，都指向文生图出的原图（角色指向第一套服装的 tag；底档不出图）。
- `_note` 照这段写："MiniMax H3-Image，官方工作流：6 步 / CFG 1 / euler / simple。文生图按标的尺寸出。编辑（带参考图的）：
  参考图先缩到约 400 万像素（保持比例、取 32 的倍数），输出按标的尺寸出（约 900 万像素，不要用 1600 万，会出噪点）；
  参考图必须是干净的文生图，不要拿编辑出来的图再编辑。"
